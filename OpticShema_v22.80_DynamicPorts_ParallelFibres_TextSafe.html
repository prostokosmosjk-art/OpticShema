Краткая инструкция

Назначение. «ОптикСхема» — автономный редактор схем PON/X-PON и карты сети. Основная схема и карта — разные рабочие области, связанные привязками объектов. Перед крупными изменениями сохраняйте проект.

1. Работа на телефоне и ПК

  • Инструменты открывает панель создания объектов; Свойства / расчёт — панель параметров выбранного объекта и расчётов.
  • ✋ Рука перемещает весь холст. Включите её и ведите пальцем по свободному месту или поверх оборудования/линий. В этом режиме не нужно попадать в пустой фон.
  • ↖ Выбор выбирает и перемещает отдельные объекты. На телефоне удерживайте объект, чтобы открыть контекстное меню. На ПК — правая кнопка мыши.
  • Масштаб: используйте кнопки «+», «−» и «Вписать», если они показаны в рабочей области. «На весь экран» расширяет рабочее место.
  • Отмена / Шаг вперёд отменяют и возвращают действия. Если после редактирования результат неожиданный, сначала отмените последнее действие.
  • Группа используется для совместного выделения/перемещения нескольких объектов. После группового перемещения проверьте соединения.

2. Основные команды верхней панели

  • Новая схема — начинает новый пустой чертёж. Сначала сохраните текущий проект, если он нужен.
  • Экспорт SVG — сохраняет изображение основной схемы в SVG. Это графический экспорт; для продолжения полноценного редактирования используйте проект или автономный HTML.
  • Сохранить проект — сохраняет схему и данные карты в файл проекта .optic.
  • Открыть проект — загружает ранее сохранённый файл проекта. После загрузки проверьте схему, подложку карты, маршруты и закрепы.
  • 📦 Экспорт HTML — создаёт отдельный автономный HTML-файл с кодом редактора и текущими данными схемы/карты. Его можно открыть в браузере без установки приложения. Экспортируйте заново после важных изменений: HTML является отдельной копией на момент экспорта.
  • Размер холста — меняет ширину/высоту рабочей области и параметры размещения содержимого; изменение размера холста само по себе не должно менять размеры объектов.
  • −15° / +15° — поворачивают выбранный объект на шаг 15°, если выбранный тип поддерживает поворот.
  • ? — открывает это руководство.

3. Инструменты создания схемы

Откройте «Инструменты», выберите нужный инструмент, затем нажмите/проведите по холсту в нужном месте. Для большинства элементов создаётся объект, который затем можно выделить и настроить. Конкретные поля зависят от типа объекта.

  • Выбор — выделить, переместить, открыть свойства и контекстное меню.
  • Линия / соединение — построить соединение между портами/точками объектов. Выбирайте фактические конечные точки; при построении с промежуточными точками добавляйте изгибы и завершайте линию на нужном порту.
  • Пигтейл синий / зелёный — создать пигтейл соответствующего цвета. Подключайте его к нужным портам и после поворота проверяйте, что наконечник коннектора остаётся у требуемой точки.
  • Текст — добавить текстовую подпись к схеме.
  • Поставить сплиттер — добавить оптический сплиттер; после размещения задайте тип и параметры в свойствах.
  • Процентный делитель — добавить делитель с процентным распределением выходов. Команда контекстного меню Поменять проценты местами меняет стороны распределения, например 70/30 на 30/70.
  • Зелёный делитель ТВ — добавить специальный зелёный делитель ТВ.
  • Муфта с разваркой — добавить муфту для организации волокон и сварок. Используйте таблицу сварок/настройку муфты, чтобы описать соответствия волокон.
  • Многожильный кабель — добавить кабельный объект; настройте количество волокон/модулей, маркировку, длину и параметры кабеля.
  • Соединить кабели по ОВ — связать соответствующие волокна нескольких кабелей единым соединением, когда требуется показать продолжение волокон по всем ОВ.
  • Соединить участки линии — связать участки линии в одну трассу/логическое соединение, если это соответствует вашей топологии.
  • Оптический конвертер — добавить оптический преобразователь.
  • SFP-модуль — добавить SFP. В свойствах проверьте тип, длину волны, разъём и TX-мощность; заявленная дальность модуля не заменяет расчёт бюджета линии.
  • OLT / шкаф — добавить узел/шкаф доступа.
  • ONT абонента — добавить абонентское оконечное устройство.
  • Точка сварки — обозначить сварное соединение волокон.
  • Гильза КДЗС — обозначить защитную гильзу сварки.
  • Кассета сварочная — добавить кассету для размещения сварок.
  • Оптический кросс / ODF — добавить кроссовое оборудование.
  • Адаптер SC/APC и Коннектор — обозначить соединительные элементы; учитывайте их потери в расчёте, если параметры расчёта это поддерживают.
  • Уровень сигнала — разместить/настроить обозначение уровня сигнала и параметры мощности в соответствующем объекте или панели расчёта.
  • Коаксиальный кабель — добавить коаксиальную линию. Настройте тип кабеля, длину, частоту и разъёмы.
  • ТВ-делитель — добавить обычный делитель ТВ.
  • ТВ-делитель по долям (70/30) — добавить направленный делитель с заданными долями выхода.
  • Ответвитель — добавить ответвляющий элемент коаксиальной сети.
  • Усилитель — добавить усилитель в коаксиальный тракт.
  • Абонентская розетка — обозначить абонентскую точку подключения.
  • F-разъём — обозначить коаксиальный разъём.
  • Источник CATV — обозначить источник ТВ-сигнала.

4. Выбор, контекстное меню и слои

  • Выделите объект, чтобы открыть его свойства. На телефоне удерживайте палец на объекте для контекстного меню; на ПК используйте правую кнопку мыши.
  • Изменить свойства — открыть параметры объекта.
  • Настроить кабель / муфту — открыть специальные настройки кабеля или муфты.
  • Копировать / Вставить / Дублировать — переносить или создавать копии объектов. После вставки проверьте их координаты и соединения.
  • Удалить — удалить выбранный объект. Убедитесь, что выбран именно нужный объект.
  • Цвет и оформление — изменить вид объекта; Масштаб / размер — изменить размеры, если доступно для этого объекта.
  • Повернуть −15° / +15° — повернуть объект; На передний план / На задний план — изменить порядок отображения.
  • Заблокировать — защитить объект от случайного перемещения; чтобы редактировать его, сначала разблокируйте.
  • Новый слой — создать слой; Переименовать — изменить имя; Перенести объект — переместить выбранный объект между слоями; Удалить слой — удалить слой после проверки его содержимого.
  • Выше / Ниже — изменить порядок слоя; Сохранить последовательность — сохранить настроенный порядок/последовательность, если эта команда доступна в текущей панели.
  • Добавить изображение в слой — вставить изображение как подложку/объект слоя. Для фоновой карты используйте соответствующий режим карты.

5. Оптические расчёты

  1. Выберите SFP/источник и откройте «Свойства / расчёт».
  2. Проверьте TX-мощность выбранного SFP, тип волокна, длину участков и затухание кабеля.
  3. Укажите потери сварок, коннекторов/адаптеров и сплиттеров там, где предусмотрены поля.
  4. Используйте Рассчитать путь от выбранного SFP или Рассчитать затухание, если эти команды доступны для выбранного объекта/линии. Результат действителен только при корректных исходных данных и корректно связанных портах.
  5. Применить к выбранной линии применяет введённые параметры к выбранной линии, а не ко всей схеме.

Подписи метража/потерь могут быть скрыты, чтобы не загромождать чертёж. Это не означает, что расчётные поля обнулены: проверяйте длину и затухание в свойствах линии. Не считайте результат подтверждённым измерением без проверки исходных параметров.

6. Коаксиальный тракт

  1. Разместите источник CATV, кабель, делители/ответвители/усилители и абонентские точки.
  2. Соедините элементы в порядке реального тракта.
  3. В свойствах кабеля укажите тип, длину и частоту; проверьте количество разъёмов и их потери.
  4. Нажмите Рассчитать коаксиальный тракт. Если результат неожиданен, проверьте типы кабелей, длины, частоту, разветвители и соединители.

7. Карта сети

  • Карта сети открывает отдельную карту. Подложка карты закреплена как фон, а объекты карты (дом, бокс, муфта, текст) редактируются отдельно.
  • Выбор выбирает объект/маршрут. Маршрут позволяет строить трассу по точкам: касайтесь карты в последовательности прохождения, добавляйте промежуточные точки и нажмите Завершить.
  • Линия по точкам используется для добавления точек/геометрии линии в режиме карты. Точка добавляет точку к редактируемой трассе; кнопки добавления/удаления точек меняют форму выбранного маршрута.
  • Задать линейку — режим калибровки: укажите две точки, расстояние между которыми известно, и задайте его в поле Эталон, м (например, 50). После успешной калибровки масштаб используется для оценки длин маршрутов. Не вводите условные 50 м, если реальная длина между точками другая.
  • Дом / Бокс / Муфта / Текст — размещают соответствующие объекты на карте. После размещения их можно перемещать и настраивать через контекстное меню.
  • Привязать схему / Привязать к схеме — связать объект карты с соответствующим объектом основной схемы. Открыть привязанную / Открыть привязанную схему — перейти к связанной схеме/объекту. После привязки проверьте, что выбрана правильная связь.
  • Подложка закреплена означает, что фон нельзя случайно сдвинуть как обычный объект. Для изменения подложки используйте предусмотренные команды изображения/карты.
  • Контекстное меню карты может содержать: переименование, привязку, открытие привязанной схемы, дублирование, изменение размера объектов карты, порядок отображения, блокировку и удаление.
  • Очистить холст очищает рабочую область карты после подтверждения. Проверьте предупреждение и не используйте команду, если хотите сохранить текущие объекты.
  • Назад к карте и К основной схеме переключают рабочие области.

8. Сохранение и перенос

  • .optic — основной формат проекта для дальнейшего редактирования схемы и карты.
  • SVG — графический формат схемы; он не заменяет сохранение проекта с картой и параметрами.
  • Автономный HTML — переносимая копия редактора вместе с данными проекта. Сохраните скачанный HTML в отдельное место; чтобы передать актуальную версию, повторите экспорт после правок.
  • После открытия проекта/HTML проверьте несколько ключевых объектов, связи, подложку и калибровку. Храните резервную копию .optic до крупных изменений.

9. Проверочный список перед использованием схемы в работе

  1. Сверьте подписи домов, боксов, муфт и номера волокон с фактической сетью.
  2. Проверьте концы линий: начало/конец должны подключаться к нужным портам.
  3. Проверьте длины кабеля, затухание, сварки, адаптеры, коннекторы и делители.
  4. Сверьте калибровку карты с реальным известным расстоянием.
  5. Сохраните .optic и экспортируйте автономный HTML, если нужна отдельная переносимая копия.

Техническое замечание. Интерфейс содержит инструменты, параметры и команды, доступность которых зависит от типа выбранного объекта. Руководство описывает назначение команд, видимых в этой сборке; оно не заменяет проверку реальных измерений и корректности данных сети.

Цвет и маркировка волокна

Цвета 1–12 — базовая маркировка. Для 13–16 добавлены условные варианты с полосой; конкретную таблицу нужно сверить со стандартом/паспортом применяемого кабеля.

Последовательности хранятся отдельно от настроек кабеля. При создании нового многожильного кабеля выбранная последовательность задаёт цвета первых волокон; остальные волокна используют стандартный порядок.

🗂 Слои и подложки

Глаз — показать/скрыть; замок — запретить редактирование. Изображение добавляется в активный слой и сохраняется внутри проекта.
Выбор снят

Настройка объекта

Для этого объекта доступны общие свойства справа: подпись, цвет и толщина линии.

Свойства выбранного объекта

Замена сохраняет положение и ID объекта. Соединения сохраняются только для совпадающих портов. Для муфты используй редактор разварки.

📏 Длина выбранной линии

По умолчанию длина новой линии — 100 м. При необходимости выбери линию и измени длину. Для расчёта от SFP выбери SFP-модуль.

По умолчанию длина не задана: метраж и потери на линии не отображаются. Укажи длину вручную, и тогда редактор покажет метраж и расчётное затухание. Затухание волокна считается как длина в км × дБ/км. Итог по трассе ориентировочный: учитываются длины соединённых линий и потери на выбранные соединения/сварки можно дополнительно внести в общий расчёт.

⚙️ Настройка автоматического GPON

Задай ориентир и максимальный допустимый уровень приёмника. Нижний уровень не ограничивается: генератор не будет добавлять делители ради достижения целевого значения.

Абоненты будут распределены между выбранными портами максимально равномерно. Плановый предел — 128 абонентов на один порт.

Обычные делители строят каскад по числу выходов. Процентные распределяют мощность между проходной и ответвлённой ветвями.

+4 dBm — исходная оценка. Для точного расчёта укажи паспортное значение установленного SFP.

Ориентир: -20.0 dBm · максимум: -18.0 dBm (минимум не ограничивается) · SFP-портов: 2 · лимит: 256 абонентов · режим: обычные 1:2/1:4/1:8/1:16 · TX OLT: 4 dBm · резерв: 1 жила(ы)

Важно: дополнительные жилы сами по себе не усиливают сигнал. Нижний уровень не является целью для выравнивания. Если сигнал превышает максимум, генератор покажет конкретные ветви и величину превышения. Он не будет вставлять делители с пустыми выходами ради затухания: корректировка выполняется только через реальные направления сети или отдельный рассчитанный аттенюатор.

🧮 Автопроектирование PON

Расчёт абонентской ёмкости и построение редактируемой схемы. Генератор создаёт нативные OLT, сплиттеры, муфты, ONT и реальные связи между портами. Повторный запуск заменяет только созданную автосхему; ручные объекты сохраняются.

Голова OLT будет размещена с выбранной стороны. Схема раскладывается по уровням с запасом места для крупных сплиттеров и абонентских ветвей.
